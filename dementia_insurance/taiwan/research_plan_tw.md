# 台灣壽險業「失智症」相關商品盤點與台日比較 — 研究計畫

**日期**：2026-11-05
**目標產出**：`report_tw.md`、`report_tw.docx`（繁體中文，附參考文獻）
**分支**：`claude/japan-dementia-insurance-products-xk7ijh`（與日本報告同倉庫，置於 `dementia_insurance/taiwan/`）

## 1. 研究目標
1. 依日本報告同一架構，盤查台灣現有壽險公司（壽險公會會員）之失智症相關商品：主約、附約（特約）分列，逐項簡介。
2. 熱銷與特殊商品介紹。
3. 補充台灣特有制度：長期照顧保險示範條款之「認知功能障礙」定義、保險金信託／安養信託、意定監護、指定代理請求、高齡投保評估等。
4. **台日比較**：市場規模、參與公司比例、給付觸發、MCI 與預防、給付形態、契約管理機制、監理與公共制度（日本公的介護保険 vs 台灣長照 2.0／3.0）、熱銷商品，並提出對台灣市場的觀察。

## 2. 分類碼（對應日本報告，依台灣商品特性調整）
| 分類碼 | 定義 |
|---|---|
| A | 失智症專屬主約：以「經診斷確定失智症」（如 CDR≥1 或 ≥2、或條款所定認知功能障礙）為主要給付事由之主約 |
| B | 失智症專屬附約 |
| C | 長期照顧／類長照／失能扶助等主約或附約，條款明示以「認知功能障礙」或「失智」為給付要件之一 |
| D | 輕度認知障礙（MCI）給付、預防給付、外溢保單中之認知相關設計 |
| E | 保費豁免（含因失智或長照狀態豁免）、契約管理（保險金信託、指定代理請求、保單聯絡人、高齡客戶機制） |
| F | 附帶服務（認知檢測、照護諮詢、防走失、協尋等非給付服務） |
| 附 | 產險公司之失智症相關商品（例：失智者走失協尋、第三人責任），作為對照 |
