## 1. 研究目標

1. **全公司地毯式搜索**：以生命保險協會全部會員公司（約 41 家）為母體，逐家盤查與「認知症」相關的商品，另附共濟（JA 共済・こくみん共済 coop・都道府県民共済 等）與少額短期保險業者作為補充。
2. **主契約與特約分開表列**：每家公司的認知症相關主約（主契約）、附約（特約／特則）、以及附帶服務分別列出。
3. **全商品簡介**：每項商品／特約皆附簡短介紹（給付觸發條件、給付形態、發售年、特色、銷售狀態）。
4. **熱銷與特殊商品專章**：整理市場先驅、銷量領先、及具獨特設計（MCI 保障、預防給付、認知症年金、契約者代理特約等）之商品。

## 2. 「認知症相關商品」的認定範圍（統一分類碼）

| 分類碼 | 定義 |
|---|---|
| A | **認知症專屬主契約**：以「認知症診斷確定」（或加上要介護認定）為主要給付事由之主契約 |
| B | **認知症專屬特約**：以認知症診斷／MCI 為給付事由之特約（一時金、年金、治療給付等） |
| C | **介護保障型（含認知症要件）**：介護保險／介護特約中，將「認知症＋要介護認定」列為明示給付要件者 |
| D | **MCI・預防型**：輕度認知障礙（MCI）診斷給付、預防給付金、健康增進型設計 |
| E | **保費豁免／契約管理型**：因認知症而保費免除之特約、契約者代理特約、指定代理請求特約、家族登錄制度等因應認知症的契約管理設計 |
| F | **附帶服務**：認知症預防・早期發現・家族支援等非給付型服務（App、檢測、相談窗口、MCI 篩檢） |

## 4. 各工單統一輸出規格

每家公司一節，內含：
1. 公司名（日文原名）／盤查結果（有・無・僅附帶服務）。
2. 表格：`分類碼｜商品／特約名稱（日文原名）｜主約/特約｜發售年月｜給付事由｜給付形態｜銷售狀態｜來源編號`。

4. 來源清單：`[Rn] 標題 — 發行者 — URL — 查閱日`。官網商品頁與新聞稿優先，媒體報導次之。
